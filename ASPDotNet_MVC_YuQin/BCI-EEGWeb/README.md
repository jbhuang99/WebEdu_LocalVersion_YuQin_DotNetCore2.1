# 五层学习事件脑电观察台（源码）

本项目是基于本地 TGAM/ThinkGear 串口设备的教育研究原型。它在 Windows 上读取设备数据，并通过仅监听 `127.0.0.1:7788` 的本地网页显示结果。源码包不包含任何采集到的脑电数据或用户个人信息。

## 文件

- `Program.cs`：本地 Web 服务、COM 串口读取、TGAM 帧解析、测量与事件 API、JSON/CSV 导出。
- `SessionModels.cs`：测量、学习事件、个人基线和五层状态的数据模型。
- `wwwroot/index.html`：实时页面、图表、事件表单和研究解释。
- `EEGWeb.csproj`：.NET 8 项目文件。

## 编译与运行

在 Windows 电脑安装 .NET 8 SDK 后，在项目目录执行：

```powershell
dotnet restore
dotnet run
```

程序默认连接 `COM5`，波特率 `9600`。运行后浏览器打开 <http://127.0.0.1:7788/>。如果端口号变化，可在网页顶部刷新并选择串口。COM 端口一次只能由一个程序占用，启动前请关闭其他正在读取该端口的程序。

生成 Windows 发行版：

```powershell
dotnet publish EEGWeb.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```

运行生成的 `EEG实时监测.exe` 即可。`--no-browser` 参数可禁止自动打开浏览器。

## 使用流程

1. 正确佩戴电极，确认信号质量下降。协议值 `200` 表示电极未接触。
2. 点击“开始测量”。可在安静、睁眼状态下采集 15 个质量合格帧作为个人静息基线。
3. 为每个学习任务填写名称并选择一层或多层标签：实践、技术、科学、人文、哲学。
4. 点击“标记事件开始”；完成任务后填写行为表现，点击“标记事件结束并保存”。
5. 点击“结束测量”，下载完整 JSON 或表格 CSV。开始新一轮前必须先导出上一轮记录。

数据只保存在程序内存中；关闭程序会清除未下载的数据。JSON 保留完整测量记录与事件，CSV 按脑电帧逐行输出并关联时间窗口内的事件。

## 研究边界

五层状态仅描述最近 5 个脑电接触质量合格、且有行为评价的事件；至少 4 个行为达标显示“稳定”，不足 5 个为“未知”。它不是已训练的五层分类器，也不能仅凭脑电认定学习效果、知识水平、价值观或哲学能力。

当前连接的设备未提供原始波形和多导联数据。因此不能可靠实现交底书中的 ICA、时域幅值稳定性 ASI、通道一致性 ICI、完整 MEQI、P300 或预训练分类概率。网页只展示设备提供的八频段功率、质量值、基线相对变化和人工行为记录；不生成未经验证的“专注指数”。设备 eSense 值为 `0` 时，按官方协议显示“不可用”。
